# Reports

> **No reports have been produced yet.** Reports are added only after real test execution, and every figure must be derived from recorded results.

## Layout

| Path | Contents |
|---|---|
| `execution/` | Manual test cycle execution summaries (`EXEC-YYYY-MM-DD-<cycle>.md`) |
| `regression/` | Manual and automated regression results (`REG-YYYY-MM-DD-<version>.md`) |
| `release/` | Release quality assessments based on [docs/release-quality-report.md](../docs/release-quality-report.md) |

## Every report must include

- Application version and environment ID(s)
- Test window (dates)
- Scope covered and not covered
- Status counts calculated from recorded test-case statuses
- Links to defect reports and sanitized evidence
- Known limitations

## Generated reports

Allure output (`allure-results/`, `allure-report/`) is generated by automation and CI and is **git-ignored**. Only curated, sanitized summaries are committed here.
